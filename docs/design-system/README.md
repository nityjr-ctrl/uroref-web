# Approved design-system intake

Place only the approved Claude Design export here. Recommended names:

- `design-system.md` — principles, components, states and responsive rules;
- `tokens.json` or `tokens.css` — named colour, type, spacing, radius and motion values;
- `homepage-desktop.png` — approved wide reference;
- `homepage-mobile.png` — approved narrow reference;
- `assets/` — original images, icons or illustrations;
- `SOURCE.md` — export date, Claude Design conversation/reference and approval notes.

Keep source files alongside rendered references. Do not put credentials, patient data, real patient imaging or private clinical documents in this folder.

Claude Code should read the root `CLAUDE.md` and `docs/CLAUDE-DESIGN-HANDOFF.md` before implementing anything from this directory.
