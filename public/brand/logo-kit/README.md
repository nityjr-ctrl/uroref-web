# UroRef five-project logo kit

This folder contains a presentation-ready logo suite for the five canonical UroRef projects:

1. UroRef
2. ProstateView
3. CalyxView
4. UrOops3D
5. Cystosight by UroRef

The quickest files to give a designer are:

- `uroref-project-logo-suite.png` — one visual contact sheet
- `presentation/*-lockup-1600.png` — transparent horizontal logos
- `presentation/*-mark-1024.png` — high-resolution square marks
- `presentation/*.svg` — editable vector originals

## What existed and what was created

| Project | Existing source identity | Presentation-suite treatment |
| --- | --- | --- |
| UroRef | Navy/amber U-shaped favicon and app icons; HTML/CSS wordmark | Existing U geometry retained and normalised to the current teal hub palette |
| ProstateView | Established blue anatomical emblem and full `.com` lockup | Original raster files preserved; a simplified vector companion was drawn for the shared suite |
| CalyxView | No standalone logo; only `CV` text placeholders | New renal collecting-system and stone mark |
| UrOops3D | No standalone logo; only `U3` text placeholders | New layered 3D teaching-frame and hazard-point mark |
| Cystosight by UroRef | No standalone logo; only `CS` text placeholders | New bladder field-of-view and cystoscopy-lens mark |

The untouched source artwork is in `originals/`:

- `uroref-favicon-original.svg`
- `uroref-app-icon-original-512.png`
- `uroref-wordmark-legacy-prostateview.svg`
- `prostateview-logo-original.png`
- `prostateview-symbol-original.png`
- `prostateview-app-icon-legacy.svg`
- `prostateview-app-icon-legacy-512.png`

The files labelled `legacy` are included for completeness, not as the recommended presentation identity. They document the older orange ProstateView app icon and the UroRef wordmark embedded in that earlier project build.

## Use

- Use an SVG wherever the destination accepts vectors.
- Use the transparent 1600 px lockup PNGs in Claude Design, presentation software, social artwork, or documents.
- Use the 1024 px square PNGs for tiles, profile cards, app-style displays, and QR landing pages.
- Keep enough clear space around a logo: at least one quarter of the square mark's width.
- Do not recolour individual anatomical or spatial elements independently.
- Do not add a medical cross, NHS lozenge, endorsement seal, or wording that implies clinical certification.

These are working presentation identities for UroRef-owned educational projects. The kit does not imply endorsement by BAUS, the NHS, a hospital, or any other external body.

## Production note

The three missing marks and the two normalised companions were drawn as deterministic SVG artwork so they remain crisp, editable, and consistent with the repository's existing vector system. No generated bitmap was used for the logo geometry.
