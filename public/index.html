06Optional feature · inside UroRefIncluded in the app

Ariadne

A thread through the pathway.

A retrieval-augmented assistant built into UroRef. Each query is routed through a Cloudflare Worker and combined with curated UroRef guidance, recent chat context and the selected hospital profile when available. Common requests are handled directly by the service; others use Google Gemini to return source-linked educational navigation, with pseudonymous rate limiting and explicit safety boundaries.

RAGSource citationsSite-aware contextCloudflare WorkerGoogle Gemini
Do not enter patient-identifiable information. Ariadne is optional, online, and off unless you turn it on.
