What the user can conclude

  • The real public-dataset case loads with named mesh nodes.
  • The MONAI inference path runs on GPU (~6 s on this hardware).
  • The GT-derived case is the one to demo for anatomy.

What the user cannot conclude

  • That MONAI's segmentation is correct on this case (input metadata was reconstructed).
  • Any model performance, Dice, accuracy, or clinical utility from one case.
  • That ProstateView is clinically validated. It is not.
