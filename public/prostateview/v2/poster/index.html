Mobile 3D prostate teaching from public MRI

Nity G, Urology ST4 · built on Prostate158 (Adams et al. 2022, CC BY 4.0)

Teaching only Public dataset Mobile 3D
Not a medical device. No diagnosis, PI-RADS, staging or biopsy targeting.

Problem

Axial prostate MRI asks learners to rebuild a 3D organ in their head. That spatial step is hard to teach from slices alone.

Approach

Expert-labelled public Prostate158 masks are converted into compact 3D models with consistent gland, zone and lesion layers.

Output

A phone-ready teaching library for screen sharing, case discussion and anatomy rehearsal, with clear limits shown throughout.

Technical validation

Technical validation

Generation output was benchmarked against expert Prostate158 labels. Whole-gland agreement is strong; zonal performance is reported transparently because PZ boundaries are the hardest part of the task.

StructureDice (mean ± SD)
Whole gland0.91 +/- 0.03

Peripheral zone0.77 +/- 0.07

GPU benchmark, n = 100. Model-vs-label agreement, not clinical validation.

Release QA

Orientation QA completed

The QA gate checks that the 3D display is oriented correctly before teaching release, so the visible model matches the MRI-derived anatomy.

14 cases passed automated orientation checks without correction. 88 required human correction, mainly for global gland orientation; lesion localisation remained anatomically correct within the gland.
